# Security

Found a security problem in Arcade Launcher? Please don't open a public issue. Message the author privately through [Ko-fi](https://ko-fi.com/amsrs) or GitHub, with steps to reproduce it, and it will be fixed as fast as possible.

Arcade Launcher collects no data, shows no ads and needs no account. It only connects to the internet for game art and info (Steam, HowLongToBeat, PCGamingWiki), wallpapers (Bing), update checks (GitHub) and, if you buy Arcade Plus, license checks (Lemon Squeezy).
